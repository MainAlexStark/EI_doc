# Панель управления руководства (19.11.2026)

Экраны поверителя («Выезды», «Приёмки», «График») остались как были. Для
старшего метролога, менеджера, руководителя и владельца (`CONTROL_ROLES` —
owner, head, metrologist, manager) поверх них — диспетчерская: вся работа всех
сотрудников и быстрое назначение.

«Поверки» переименованы в **«Приёмки»** (заказы: приборы привезли сами).

## Что видит руководство

| Раздел | Что там |
|---|---|
| **Панель** (новая, открывается первой) | Цифры по фирме — адреса за день, заявки без исполнителя, выезды без даты, приёмки к выдаче, протоколы на нормоконтроле, просроченные задачи (каждая ведёт в свой раздел). Карточка каждого сотрудника: где он (командировка / выезды / свободен / нет в графике), адреса за день и сколько отработано, приёмки, черновики, на нормоконтроле, задачи, адреса на неделю. «Требует внимания» — назначить прямо здесь. Листается по дням. |
| **Выезды → Карта** (по умолчанию) | Все адреса за день / 3 дня / неделю на одной карте, цвет — поверитель, номер — порядок в его маршруте, пунктир — маршрут. Пунктирные кольца — неназначенные заявки и выезды без даты. Клик — выбрать, Shift/⌘+клик или Shift+рамка — несколько; справа — день и одно касание по человеку. Легенда скрывает/показывает поверителей. |
| **Приёмки** | Таблица всех заказов: стадия, приборы, ответственный — выбором прямо в строке; галочки + «Отдать» пачкой; «Выдано» и акты без захода в заказ. |
| **График → Команда** | Сотрудники × дни (неделя / 2 недели): слоты, адреса, командировки, задачи, приёмки. Клик по клетке — поставить/убрать слот (весь день, 08–12, 13–17, своё время, в районе/командировка) и отдать неназначенное на этот день. «Мой» — прежний личный календарь. |
| **Сотрудники** (новый) | Завести сотрудника одним действием (ФИО, должность, таб. №, почта → учётная запись + временный пароль, показывается один раз), изменить роль/почту, сбросить пароль, уволить/вернуть. Менять — владелец и руководитель, остальное руководство смотрит. |

Цвет сотрудника один и тот же везде (по порядку id, палитра общего журнала).

## Правила назначения (`apps/logistics/dispatch.py`)

Одни для экранов и ассистента:

- адрес дня в городе → переезжает в день другого поверителя/на другую дату (`city_day_for`), наряд меняет исполнителя и дату; опустевший автоматический день удаляется;
- адрес командировки → исполнитель наряда внутри той же командировки (не участник добавляется в состав), дата — только в пределах командировки;
- наряд на выезд без даты → исполнитель + дата → сразу в день поверителя (`attach_to_city_day`);
- приёмка → ответственный;
- заявка с сайта → подтверждение нарядом (`hub.service.confirm_request`);
- отмеченные адреса, закрытые выезды/наряды и адреса с поверками другого поверителя не переназначаются.

API: `GET /api/dispatch/overview/?date=`, `GET /api/dispatch/map/?date_from=&date_to=`,
`GET /api/dispatch/schedule/?date_from=&date_to=`, `POST /api/dispatch/assign/`
(`{items:[{type: stop|order|request, id}], employee_id, date?, time?}` — пачкой, по каждому своя ошибка);
`GET/POST /api/core/staff/`, `PATCH /api/core/staff/<id>/`, `POST /api/core/staff/<id>/password/` (`apps/core/staff.py`).

Метролог теперь тоже может менять график других сотрудников (`api_availability.MANAGE_ANY_ROLES`).

## Ассистент — администрирование (`apps/assistant/admin_tools.py`)

- `ei_team` — панель на день; `ei_dispatch_board` — карта и очередь неназначенного с id; `ei_team_schedule` — командный график;
- `ei_assign_propose` — назначение пачкой одной карточкой;
- `ei_staff`, `ei_staff_propose` — сотрудники: завести, изменить, уволить/вернуть, сбросить пароль.

Изменения — карточкой «Подтвердить», права проверяются заново при нажатии. Временный пароль видит только человек в карточке (`action.result`), в текст события для модели он не попадает.
