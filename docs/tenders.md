# Госзакупки

Код: `backend/apps/hub/tenders.py`, вкладка «Закупки» (менеджер,
руководитель, владелец).

- **Поиски** — сохранённые запросы к ЕИС (zakupki.gov.ru): текст, код
  региона (43 — Кировская область), законы 44/223-ФЗ.
- Celery beat в 8:10, 13:10 и 17:10 прогоняет активные поиски, новые
  закупки сохраняет (без дублей по реестровому номеру) и присылает в Telegram
  владельцу, руководителю и менеджерам с привязанным ботом.
- Воронка: новые → изучаем → подали → выиграли / не выиграли / не интересно,
  с заметкой.

## Откуда данные

Открытого JSON API поиска у ЕИС нет. Используется RSS-выдача расширенного
поиска — тот же поиск, что на сайте. Разбор устойчив к мелочам (номер из
ссылки или заголовка, цена, заказчик и срок — по подписям в описании), но
формат ЕИС не документирован и меняется. **Перед первым использованием — на
сервере:**

```bash
docker compose exec web python manage.py tenders_probe "поверка счетчиков воды" --region 43
```

Покажет, сколько закупок разобралось и что в полях. Пусто при живом сайте —
поменялась разметка: правятся регулярные выражения в начале `tenders.py`.
ЕИС иногда не отвечает зарубежным адресам и ботам — тогда `TENDERS_PROXY`.

Из среды разработки ЕИС была недоступна, поэтому разбор проверен на образце
RSS (`apps/hub/tests/fixtures/eis_rss.xml`), а не на живой выдаче.
