# Выезды: командировки и маршруты

Код: `backend/apps/logistics/` (`service.py`, `routing.py`), экран — вкладка
«Выезды». Права: планирует диспетчерская роль (`logistics.plan_trips` —
владелец, руководитель, менеджер), поверитель видит свои командировки и
отмечает остановки (`logistics.view_trips`).

## Как планируется выезд

1. **Спрос.** На карте и по районам — то, что накопилось за выбранное окно
   (14–180 дней):
   - открытые наряды без командировки (синие);
   - новые заявки с сайта (оранжевые) — сначала подтверждаются во вкладке
     «Заявки» и становятся нарядами;
   - экземпляры СИ, у которых последняя годная поверка истекает в окне
     (серые) — повод обзвонить владельцев.
2. **Командировка** создаётся из нарядов района на выбранные даты. Наряд
   может быть только в одной командировке. Исполнители нарядов становятся
   поверителями командировки.
3. **Маршрут** («Построить маршрут»):
   - остановки с назначенной датой остаются в своём дне;
   - остальные выстраиваются в общий порядок объезда от офиса и режутся на
     дни по вместимости рабочего дня (`LOGISTICS_DAY_MINUTES`) — соседние по
     дороге объекты попадают в один день;
   - каждый день упорядочивается отдельно, с расчётным временем прибытия;
     время наряда (`scheduled_time`) — окно в час; опоздания и перегруз дня
     показываются предупреждением.
4. **Эталоны** бронируются на даты командировки. Бронь отказывает, если
   эталон уже уехал в пересекающуюся командировку или его поверка
   заканчивается раньше конца выезда.
5. **Пакет на выезд (PDF)** — маршрутный лист по дням (адрес, клиент,
   контакт, порядок допуска, эталоны с собой) и по два печатных бланка с QR
   на каждый режимный объект.
6. **План/факт.** Закрытый наряд отмечает остановку выполненной сам;
   поверитель может отметить «выполнено» / «не состоялось» с причиной.
   Считаются поверки, непригодные и рубли на поверку по фактическим расходам.

## Расстояния и порядок

- **OSRM** (`LOGISTICS_OSRM_URL`) — время и километры по дорогам. Поднимается
  отдельным профилем compose: `deploy/osrm.sh volga-fed-district`, затем
  `LOGISTICS_OSRM_URL=http://osrm:5000`. Недоступен — тихо считаем по прямой.
- **По прямой** — гаверсинус × `LOGISTICS_DETOUR_FACTOR` (1,35) при
  `LOGISTICS_SPEED_KMH` (32 км/ч).
- **Порядок** — OR-Tools с временными окнами, если установлен
  (`pip install ortools`, в образ не входит: +30 МБ); иначе ближайший сосед +
  2-opt. На 10–20 объектах в день разница — единицы процентов.

PostGIS не понадобился: координаты — обычные широта/долгота у объекта и
заявки (приходят из подсказки адреса DaData), расчёты — в Python.

## Карта

MapLibre с растровой подложкой `MAP_TILE_URL`. Тайлы
`tile.openstreetmap.org` годятся только для пробы — их правила запрещают
рабочую нагрузку; для работы нужен свой тайл-сервер или провайдер. Тайлы на
район командировки офлайн не предзагружаются: в поле маршрут нужен в
маршрутном листе, а карта — у диспетчера.
