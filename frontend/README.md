# EI_doc — веб-журнал

React + TypeScript + Vite. Пока два экрана: журнал поверок и нормоконтроль.
Офлайн-режим и ввод измерений с телефона — этап 3.

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173, /api проксируется на localhost:8000
```

Бэкенд при этом должен быть поднят: `cd ../backend && python manage.py runserver`.

## Сборка

```bash
npm run build        # dist/
```

В бою `dist/` раздаёт тот же nginx, что и Django, поэтому CORS не нужен —
фронт и API на одном origin.

## Как устроено

- `src/api.ts` — единственное место, где живёт HTTP. Access-токен короткий
  (15 минут), поэтому на 401 клиент один раз обновляет пару и повторяет
  запрос: иначе метролог разлогинивался бы посреди работы.
- `src/components/Journal.tsx` — таблица с фильтрами и выгрузкой в Excel.
  Поиск с задержкой, чтобы не дёргать сервер на каждую букву.
- `src/components/Normocontrol.tsx` — области нумерации. Кнопка «Пересчитать»
  появляется только после предпросмотра: метролог сначала видит, какие номера
  сдвинутся, и лишь потом применяет.
