Политика обработки персональных данных

Редакция от {{ version }}. Оператор — {{ org.full_name }}{% if org.inn %}, ИНН {{ org.inn }}{% endif %}{% if org.ogrn %}, ОГРН {{ org.ogrn }}{% endif %}, {{ org.address }}.

1. Какие данные мы обрабатываем

Имя (или наименование организации), телефон, адрес электронной почты, адрес объекта, где установлены средства измерений, сведения о самих средствах измерений, комментарий к заявке, IP-адрес, с которого отправлена заявка.

2. Зачем

  • принять и выполнить заявку на поверку: связаться, согласовать время, приехать по адресу;
  • заключить и исполнить договор;
  • передать сведения о результатах поверки в Федеральный информационный фонд по обеспечению единства измерений (ФГИС «Аршин») — это обязанность поверителя по Федеральному закону № 102-ФЗ «Об обеспечении единства измерений»;
  • защитить форму заявки от спама (IP-адрес).

3. Основания

Согласие субъекта (отметка в форме заявки), исполнение договора, исполнение обязанностей, возложенных на оператора законом (ст. 6 Федерального закона № 152-ФЗ).

4. Сроки хранения

  • отклонённые заявки и спам — {{ rejected_days }} дней, затем данные обезличиваются;
  • исполненные и неисполненные заявки — {{ retention_years }} года с даты заявки, затем обезличиваются;
  • протоколы и сведения о поверке, переданные в ФГИС «Аршин», хранятся в сроки, установленные законодательством об обеспечении единства измерений, — на них отзыв согласия не распространяется.

5. Кому передаются

ФГИС «Аршин» (сведения о поверке, без контактных данных). Для подсказки адреса на форме используется сервис DaData, для защиты от спама — Yandex SmartCaptcha. Данные хранятся на серверах в Российской Федерации.

6. Ваши права

Вы можете узнать, какие ваши данные мы храним, потребовать их уточнения, блокирования или уничтожения, отозвать согласие. Напишите{% if org.email %} на {{ org.email }}{% endif %}{% if org.phone %} или позвоните {{ org.phone }}{% endif %} — ответим в течение 10 рабочих дней (ст. 14, 20 152-ФЗ).

7. Как защищаем

Доступ к данным — только у сотрудников, которым он нужен для работы, по личным учётным записям; передача — по шифрованному соединению; действия с данными журналируются; резервные копии хранятся зашифрованными.
